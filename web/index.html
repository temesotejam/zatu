M5Stack Core2 / ESP32

Port A 周辺機器チェッカー

開発環境をインストールせず、USB接続したCore2へブラウザからファームウェアを書き込みます。

書き込み前の安全確認

これはCore2専用です。CoreS3には書き込まないでください。意図しない動作を防ぐため、サーボとVESCは無負荷または切り離した状態で作業してください。

書き込み

  1. Core2をUSB Type-CケーブルでPCへ接続します。
  2. 下のボタンを押し、CP210xまたはCH9102系のCOMポートを選択します。
  3. 画面の案内に従ってインストールします。

このブラウザはWeb Serial書き込みに対応していません。PC版ChromeまたはEdgeで開いてください。

安全なHTTPSページから開く必要があります。

ポートが表示されない場合は、通信可能なUSBケーブル、USBシリアルドライバ、Core2の電源状態を確認してください。

書き込み後に確認できる機器

SERVOPCA9685 / I²C
DISTANCEVL53L5CX / I²C
POWERINA226 / I²C
MOTORVESC / UART

Core2 Port Aは、黄=GPIO32、白=GPIO33、黒=GND、赤=5Vです。3.3V専用機器へ赤線の5Vを接続しないでください。
